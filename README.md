# STEINS;GATE RE:BOOT — українізатор

Машинний, частково редагований переклад - деякі частини можуть бути дивно/некоректно перекладені.
Буде оновлюватись по ходу проходження.
Перекладено: увесь сценарій (24 524 репліки), довідник TIPS (290 статей), листи в телефоні, блок-схема, меню й написи на кнопках.

Переклад зроблено базуючись **з японського оригіналу**; англійські саби як
підказка — він місцями вільний і подекуди відходить від змісту.

> Це неофіційний, некомерційний фанатський проєкт. Він не пов'язаний із 5pb./MAGES., Spike Chunsoft
> чи будь-яким видавцем і не містить жодних файлів гри. Щоб грати, потрібна власна копія гри.

## Як поставити

Текст гри лежить не окремими файлами, а всередині архівів, разом з усіма мовами одразу —
тож переклад не додає нічого нового, а оновлює ці архіви. Написи на кнопках, у меню й на
плашках імен узагалі не текст, а картинки, і їх доводиться перемальовувати.

Готові пропатчені архіви важать понад гігабайт (самий лише `motion_body.bin` — близько 940 МБ),
тож викладати їх для завантаження безглуздо. Замість цього інсталятор на 22 МБ везе з собою
самі рядки перекладу й збирає все на вашому боці, з вашої ж копії гри.

**Найпростіше.** Завантажте `SGRE-UA-Setup.exe` з розділу [Releases](../../releases) і запустіть.
Він спитає, що робити: **поставити українізатор** чи **повернути англійську**. Встановлення
триває хвилину-дві, весь хід видно в консолі.

Патч сам знайде гру в Steam; якщо не знайде — відкриє вікно вибору теки. Можна вказати й теку
рівнем вище (хоч усю бібліотеку Steam) — гру він там знайде сам.

Windows покаже «SmartScreen заблокував запуск невідомого застосунку» — так буває з будь-якою
програмою без платного сертифіката підпису. Натисніть «Детальніше» → «Виконати попри все».
В описі релізу є SHA-256 файлу: якщо хочете, звірте його перед запуском.

**Що робить exe.** Це той самий `patcher/patch.py` із цього репозиторію. Він не лізе в мережу,
не чіпає реєстр і не встановлюється в систему: знаходить теку гри, переписує чотири архіви
й завершується. Не хочете запускати чужий exe — зберіть свій із того самого джерела, перед тим
перевіривши:

```
pip install pyinstaller pillow fonttools zstandard
python build_exe.py
```

**Вручну (якщо маєте Python 3.10+).**

```
pip install pillow fonttools zstandard
python -m patcher.patch
```

Ключі (щоб не питало): `--install` — ставити одразу; `--restore` — повернути англійську;
`--game "D:\Steam\steamapps\common\SGRE"` — вказати теку гри; `--only scenario config font ui` —
поставити лише частину.

Гру патч шукає сам: на Windows питає реєстр, де стоїть Steam, читає його список бібліотек і бере
теку з маніфесту гри. Тому працює й тоді, коли гра лежить на іншому диску або в теці з іншою
назвою. Оригінали архівів лягають у `wind3d11data/_orig` **до** будь-яких змін, тож відкат
працює навіть після невдалого встановлення.

## Steam Deck і Linux

У релізі є й лінуксова збірка — `SGRE-UA-Setup`, без розширення. Гра на Deck іде під Proton,
але файли лежать звичайним лінуксовим шляхом, тож патч працює з ними так само. Запускати
з режиму робочого столу:

```
chmod +x SGRE-UA-Setup && ./SGRE-UA-Setup
```

**На живому Deck не перевірено.** Збірка автоматична (GitHub Actions, той самий код), запуск
і поведінку без гри перевірено на Linux, але саме встановлення на Deck ніхто не проходив.
Якщо спробуєте — заводьте issue з тим, що вийшло.

**Після встановлення** запустіть гру й у налаштуваннях оберіть мову **Українська**.

## Що робить патч

| Частина | Що змінює |
|---|---|
| `scenario` | увесь сюжетний текст і репліки |
| `config` | системні написи, блок-схему, телефон, TIPS, листи, документи |
| `font` | збирає шрифт із кирилицею (гарнітура гри + Source Sans 3) |
| `ui` | перемальовує написи на кнопках, меню й плашках імен |

Оригінальні файли зберігаються в `wind3d11data/_orig` — звідти працює відкат. Патч нічого не
видаляє й не чіпає збереження.

**Відео лишаються англійськими.** Текст у роликах (пролог, кінцівки) намальований прямо в кадрах,
а не показаний субтитрами, тож підмінити його доволі ресурсоємко. Так само з написами всередині
сюжетних ілюстрацій — вивісками, газетами.

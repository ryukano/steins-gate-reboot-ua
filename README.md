# STEINS;GATE RE:BOOT — українізатор

Машинний, частково редагований переклад - деякі частини можуть бути дивно/некоректно перекладені.
Буде оновлюватись по ходу проходження.
Перекладено: увесь сценарій (24 524 репліки), довідник TIPS (290 статей), листи в телефоні, блок-схема, меню й написи на кнопках.

Переклад зроблено базуючись **з японського оригіналу**; англійські саби як
підказка — він місцями вільний і подекуди відходить від змісту.

> Це неофіційний, некомерційний фанатський проєкт. Він не пов'язаний із 5pb./MAGES., Spike Chunsoft
> чи будь-яким видавцем і не містить жодних файлів гри. Щоб грати, потрібна власна копія гри.

## Як поставити

Переклад не можна просто скопіювати в теку гри: він не додає файлів, а перебирає її архіви —
текст лежить усередині них разом з усіма мовами. Тому потрібен інсталятор, який зробить це
з вашою копією.

**Найпростіше.** Завантажте `SGRE-UA-Setup.exe` з розділу [Releases](../../releases), запустіть,
дочекайтеся напису «Готово». Патч сам знайде гру в Steam; якщо не знайде — попросить вказати теку.

Windows покаже «SmartScreen заблокував запуск невідомого застосунку» — так буває з будь-якою
програмою без платного сертифіката підпису. Натисніть «Детальніше» → «Виконати попри все».
В описі релізу є SHA-256 файлу: якщо хочете, звірте його перед запуском.

**Що робить exe.** Це той самий `patcher/patch.py` із цього репозиторію. Він не лізе в мережу,
не чіпає реєстр і не встановлюється в систему: знаходить теку гри, переписує чотири архіви
й завершується. Не хочете запускати чужий exe — зберіть свій із того самого джерела, перед тим
перевіривши:

```
pip install pyinstaller pillow fonttools zstandard
python build_exe.py
```

**Вручну (якщо маєте Python 3.10+).**

```
pip install pillow fonttools zstandard
python -m patcher.patch
```

Ключі: `--game "D:\Steam\steamapps\common\SGRE"` — вказати теку гри; `--restore` — повернути
англійську; `--only scenario config font ui` — поставити лише частину.

Гру патч шукає сам: питає реєстр, де стоїть Steam, читає його список бібліотек і бере теку з
маніфесту гри. Тому працює й тоді, коли гра лежить на іншому диску або в теці з іншою назвою.
Оригінали архівів лягають у `wind3d11data/_orig` **до** будь-яких змін, тож `--restore` повертає
все навіть після невдалого встановлення.

**Після встановлення** запустіть гру й у налаштуваннях оберіть мову **English** — саме в цей слот
покладено українську.

## Що робить патч

| Частина | Що змінює |
|---|---|
| `scenario` | увесь сюжетний текст і репліки |
| `config` | системні написи, блок-схему, телефон, TIPS, листи, документи |
| `font` | збирає шрифт із кирилицею (гарнітура гри + Source Sans 3) |
| `ui` | перемальовує написи на кнопках, меню й плашках імен |

Оригінальні файли зберігаються в `wind3d11data/_orig` — звідти працює відкат. Патч нічого не
видаляє й не чіпає збереження.

**Відео лишаються англійськими.** Текст у роликах (пролог, кінцівки) намальований прямо в кадрах,
а не показаний субтитрами, тож підмінити його доволі ресурсоємко. Так само з написами всередині
сюжетних ілюстрацій — вивісками, газетами.

## Для бажаючих допомогти з перекладом

Побачили кривий рядок — заводьте issue. Достатньо:

* **скріншот** (найшвидше — клавіша Print Screen);
* **текст**, як він виглядає в грі;
* **де це було**: розділ і приблизно місце в ньому;
* **що не так** і, якщо є думка, як краще.

У `docs/` лежить те, за чим тримався стиль: глосарій термінів, правила проти кальок, матриця
стилів для різних типів тексту й глосарій написів інтерфейсу.

Опис голосів персонажів сюди не клали навмисно: він розписаний по сюжетних етапах і рясніє
спойлерами аж до фіналу.
